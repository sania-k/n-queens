# Project 2: n-queens using Hill Climbing
Authors: Janvi Nandwani, Sania Khan
ITCS 6150

To run, download `nqueens.py` and run via terminal with `python nqueens.py`. You will then be prompted to define the size n of the chessboard. Then, all the variations of n queen will be run and the results will be printed to the terminal and written to `[n]queens_results.txt`
